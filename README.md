# Rui Zhou — Academic Homepage

This is a **single-file** academic homepage: `index.html` contains all CSS and JavaScript. It is inspired by the structure and hierarchy of https://fouierl.github.io/chenxuwu.github.io/, while being independently styled for Rui Zhou.

## Replace the existing website

1. Open the GitHub repository for `mohuachou.github.io`.
2. Back up the existing homepage.
3. Replace the root `index.html` with the supplied file and commit it.
4. Keep the existing `images/` folder if available. The HTML uses `images/me.jpg`, `images/paper_gcsmim.jpg` and `images/paper_petct.jpg`; if these files are absent, built-in visual fallbacks appear instead. The page still works without them.
5. GitHub Pages should display the new page once the site rebuild is complete.

No npm, Jekyll, CSS framework, or external JavaScript is required.
